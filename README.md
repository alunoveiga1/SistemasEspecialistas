# AutoExpert — Sistema Especialista para Triagem e Diagnóstico Preliminar de Falhas Automotivas

O **AutoExpert** é um sistema especialista desenvolvido em **Python** com o objetivo de auxiliar na triagem inicial e no diagnóstico preliminar de falhas automotivas a partir dos sintomas relatados pelo usuário.

---

## Objetivo do Projeto

Simular o raciocínio de um especialista na área automotiva por meio de regras lógicas, identificando possíveis causas de problemas mecânicos
ou elétricos e orientando o usuário sobre os próximos passos recomendados (como verificação preventiva ou busca imediata por uma oficina).

---

## Funcionalidades

- **Coleta de sintomas:** interface interativa para o usuário informar sinais apresentados pelo veículo (ex.: falhas na partida, ruídos, superaquecimento, luzes no painel).
- **Motor de inferência:** cruzamento dos sintomas informados com uma base de conhecimento estruturada em regras condicionais.
- **Diagnóstico preliminar:** exibição das prováveis causas da falha e sugestões de ação.

---
